# Install

Two ways onto a phone: the signed artifacts on the v1.0 release, or a build from
source. Read the caveat on the iOS artifact before you rely on it.

## From the release

<https://github.com/saxill/habits/releases/tag/v1.0> attaches two files.

### Android — `habits-android-debug.apk` (18 MB)

Debug-signed, so it installs on any Android phone (minSdk 26) with nothing else
needed. Either `adb install habits-android-debug.apk`, or copy the file to the
phone and tap it (allow "install unknown apps" for the file manager the first
time).

### iOS — `Habits.ipa` (1.0 MB)

**Development-signed.** This is the important part: the IPA is signed under Apple
team `K75VPCXM64` with a development provisioning profile, so it installs **only
on the single iPhone registered to that team**. It will not install on any other
device, and it is not a TestFlight or App Store build.

Its provisioning profile **expires 2026-10-13**. After that date the app stops
launching until it is rebuilt and reinstalled — the binary is still on the phone,
but iOS will refuse to run it. If you are not that one registered device, or that
date has passed, build from source instead.

## From source

### iOS

Requires Xcode 16+ on macOS. The project is generated by xcodegen from
[`ios/project.yml`](../ios/project.yml); `ios/README.md` has the full run steps,
the headless `xcodebuild` recipe, and the debug driving hooks. In short:

```bash
brew install xcodegen          # once
cd ios && xcodegen generate
open Habits.xcodeproj          # pick the Habits scheme + an iPhone sim, Cmd+R
```

To get it onto a device, select your own team in Xcode's Signing & Capabilities
tab; the checked-in `DEVELOPMENT_TEAM` is the one the release IPA is signed with,
not necessarily yours.

### Android

Requires JDK 17 and the Android SDK. Set the SDK location in
`android/local.properties` (this file is gitignored, so each machine has its own):

```properties
sdk.dir=/usr/local/share/android-commandlinetools
```

Then, from `android/`:

```bash
./gradlew testDebugUnitTest   # the unit tests — no device, no network
./gradlew assembleDebug       # the debug APK
./gradlew assembleRelease     # the release APK
```

`android/README.md` covers the module layout and the iOS→Android mapping.
`assembleRelease` has no `signingConfig` declared, so the release APK it produces
is unsigned — install the debug APK, or sign the release one yourself.

Build config, from [`android/app/build.gradle.kts`](../android/app/build.gradle.kts):
`minSdk 26`, `targetSdk 35`, `compileSdk 35`, Java/Kotlin target 17.
